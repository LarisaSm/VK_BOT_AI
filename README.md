# VK-бот с AI-ответами

Бот для сообщества ВКонтакте: здоровается с новыми участниками и отвечает на личные сообщения с помощью нейросети. Подключается к локальной модели (Ollama, LM Studio), к любому OpenAI-совместимому API (OpenRouter, Groq) или к GigaChat.

## Что умеет

- **Приветствие.** Пишет «Привет, {имя}!», когда человек вступает в сообщество, разрешает сообщения или нажимает «Начать».
- **Ответы AI.** Отвечает на любое текстовое сообщение в личке. Пока модель думает, в чате висит «⏳ Думаю…», потом это сообщение заменяется ответом.
- **Память диалога.** Помнит последние сообщения каждого пользователя (по умолчанию 10). История хранится в памяти и сбрасывается при перезапуске.
- **Сброс.** Команда `сброс` или `/reset` начинает разговор заново.

## Установка

Нужен Python 3.10 или новее.

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Затем заполните `.env` (см. ниже) и запустите:

```bash
python bot.py
```

В логе должно появиться: `Бот запущен, AI-провайдер: …, таймаут ответа: … с`.

## Настройка сообщества ВКонтакте

В разделе **Управление → Работа с API**:

1. **Ключи доступа**: создайте ключ с правами «Сообщения сообщества» и «Управление сообществом». Вставьте его в `VK_BOT_TOKEN`.
2. **Long Poll API**: включите и отметьте типы событий:
   - входящее сообщение;
   - вступление в сообщество;
   - разрешение на получение сообщений.

В разделе **Управление → Сообщения** включите сообщения сообщества, а в «Настройках для бота» включите возможности ботов.

## Настройки `.env`

| Переменная | Что задаёт |
|---|---|
| `VK_BOT_TOKEN` | Ключ доступа сообщества |
| `AI_PROVIDER` | `stub` (заглушка без AI), `openai` или `gigachat` |
| `AI_SYSTEM_PROMPT` | Инструкция для модели: роль и стиль ответов |
| `AI_HISTORY_SIZE` | Сколько последних сообщений передавать модели |
| `AI_TIMEOUT` | Сколько секунд ждать ответа модели |

Начните с `AI_PROVIDER=stub`: бот будет повторять ваше сообщение. Так удобно проверить связь с VK до подключения модели.

### `AI_PROVIDER=openai`

| Переменная | Что задаёт |
|---|---|
| `AI_BASE_URL` | Адрес API, примеры ниже |
| `AI_API_KEY` | Ключ API (для локальных моделей не нужен) |
| `AI_MODEL` | Название модели, например `qwen3.5:4b` |
| `AI_REASONING_EFFORT` | Для «думающих» моделей: `none` — отвечать сразу, `low`/`medium`/`high` — с размышлениями, пусто — модель решает сама |

| Сервис | `AI_BASE_URL` |
|---|---|
| Ollama | `http://localhost:11434/v1` |
| LM Studio | `http://localhost:1234/v1` |
| OpenRouter | `https://openrouter.ai/api/v1` |
| Groq | `https://api.groq.com/openai/v1` |

Для «думающих» моделей вроде qwen3 рекомендуется `AI_REASONING_EFFORT=none`. Иначе модель может потратить всё окно контекста на размышления и прислать пустой ответ, тогда бот напишет «Не знаю, что ответить 🤔».

### `AI_PROVIDER=gigachat`

| Переменная | Что задаёт |
|---|---|
| `GIGACHAT_AUTH_KEY` | Ключ авторизации из [developers.sber.ru/studio](https://developers.sber.ru/studio) |
| `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` для физлиц |
| `GIGACHAT_MODEL` | Модель, по умолчанию `GigaChat` |
| `GIGACHAT_CA_BUNDLE` | Путь к сертификату Минцифры (`russian_trusted_root_ca.cer`) |
| `GIGACHAT_VERIFY_SSL` | `false` — отключить проверку SSL, если сертификата нет |

## Структура проекта

```
bot.py                  точка входа
config.py               чтение настроек из .env
handlers/
  welcome.py            приветствие
  chat.py               ответы AI, «Думаю…», сброс истории
ai/
  base.py               общий интерфейс AI-клиента
  stub.py               заглушка
  openai_compatible.py  Ollama, LM Studio, OpenRouter, Groq
  gigachat.py           GigaChat
```

Чтобы добавить новый провайдер, создайте класс-наследник `AIClient` в `ai/` и подключите его в `ai/__init__.py`.

## Если что-то не работает

- **Бот отвечает «Извините, сейчас не получается ответить».** Причина есть в логе, в строке `Ошибка AI для пользователя …`: модель недоступна, не уложилась в `AI_TIMEOUT` или вернула ошибку.
- **Бот отвечает «Не знаю, что ответить».** Модель вернула пустой текст. В логе будет предупреждение с `finish_reason`. Для «думающих» моделей поставьте `AI_REASONING_EFFORT=none`.
- **Изменения в `.env` не действуют.** Настройки читаются только при запуске, перезапустите бота.
- **Нет индикатора «печатает…».** VK не позволяет включить его ключом сообщества, поэтому вместо индикатора бот пишет «⏳ Думаю…».
